# BeenLikeLocal

A travel website to explore destinations like a local.

## Tech Stack
- Next.js
- React
- Tailwind CSS

## Getting Started

Run the development server:

npm run dev

Open http://localhost:3000 in your browser.

## Live Website

https://been-like-local.vercel.app/

## Features

- Destination guides
- Local travel experiences
- Beautiful responsive UI

## Deployment

Deployed using Vercel.
